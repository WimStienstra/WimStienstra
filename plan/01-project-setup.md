# Step 01 — Project Setup

## Objective
Scaffold a fresh Angular 21 application inside the existing `WimStienstra/WimStienstra` repository using the Angular CLI, install all dependencies (including Pretext, GSAP, and Boneyard), and verify the dev server and build work.

---

## Prerequisites
- Node.js **22.x LTS** (Angular 21 supports `^20.19.0 | ^22.12.0 | ^24.0.0` — Node 22 LTS recommended)
- Angular CLI 21: `npm install -g @angular/cli@21`
- TypeScript **5.9.x** (Angular 21 requires `>=5.9.0 <6.0.0` — installed automatically by the CLI)
- The repository is cloned locally at the root

---

## Tasks

### 1. Scaffold Angular App
Run in the repo root. The portfolio **is** the repo, so scaffold directly here.

```bash
ng new wimstienstra --directory . --routing false --style scss --skip-git
```

Flags:
- `--directory .` — scaffold into the current directory
- `--routing false` — single-page app, no router needed
- `--style scss` — SCSS for all component styles
- `--skip-git` — don't reinitialise git (repo already exists)

> **Note:** `--standalone` is the default in Angular 21 (no `NgModules` generated by default) so the flag is not needed.

Accept any overwrite prompts for `package.json`, `tsconfig.json`, `README.md`.

### 2. Install Dependencies

```bash
npm install @chenglou/pretext
npm install gsap@3        # 3.14.x — fully free, all plugins included
npm install boneyard-js
npm install lucide-angular
```

> **GSAP is now fully free** (as of Webflow sponsorship). `ScrollTrigger` and all premium plugins are included — no license key or member account needed. Just `import { ScrollTrigger } from 'gsap/ScrollTrigger'`.

### 3. Enable JSON Imports
In `tsconfig.json`, ensure `resolveJsonModule` is enabled so content JSON files can be imported directly:

```json
{
  "compilerOptions": {
    "resolveJsonModule": true,
    "esModuleInterop": true
  }
}
```

> Angular 21 requires TypeScript **≥ 5.9.0 < 6.0.0** — installed automatically by `ng new`. Do not pin a different TypeScript version manually.

### 4. Configure `angular.json` for Static Hosting
Set `baseHref` so all asset paths resolve correctly when the site is served from the root of `wimstienstra.nl`:

In `angular.json`, under `projects.wimstienstra.architect.build.options`:
```json
{
  "baseHref": "/"
}
```

Also confirm the `assets` glob includes the `public/` folder (Angular 17+ default — should be present automatically).

> **Static hosting compatible:** `ng build` produces a folder of pure static files (HTML, CSS, hashed JS bundles). There is no server-side component — the output can be uploaded to **any** web host.

### 5. Create Boneyard Config
Create `boneyard.config.json` in the repo root:

```json
{
  "breakpoints": [375, 768, 1280],
  "out": "./src/bones",
  "wait": 1000,
  "color": "rgba(74, 240, 200, 0.08)",
  "darkColor": "rgba(74, 240, 200, 0.06)",
  "animate": "shimmer"
}
```

> The `shimmer` animation on the accent color creates a subtle cyan glow that matches the site's design language.

### 6. Update `AppComponent` Shell
Replace the generated `src/app/app.component.ts` / `.html` with a minimal shell that declares all section components:

```typescript
// src/app/app.component.ts
import { Component } from '@angular/core'
import { HeroComponent }       from './components/hero/hero.component'
import { AboutComponent }      from './components/about/about.component'
import { ExperienceComponent } from './components/experience/experience.component'
import { ProjectsComponent }   from './components/projects/projects.component'
import { SkillsComponent }     from './components/skills/skills.component'
import { HobbiesComponent }    from './components/hobbies/hobbies.component'
import { ContactComponent }    from './components/contact/contact.component'

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [
    HeroComponent,
    AboutComponent,
    ExperienceComponent,
    ProjectsComponent,
    SkillsComponent,
    HobbiesComponent,
    ContactComponent,
  ],
  templateUrl: './app.component.html',
})
export class AppComponent {}
```

```html
<!-- src/app/app.component.html -->
<main>
  <app-hero />
  <app-about />
  <app-experience />
  <app-projects />
  <app-skills />
  <app-hobbies />
  <app-contact />
</main>
```

### 7. Create Stub Components
Use the Angular CLI to generate all section components as stubs:

```bash
ng generate component components/hero       --inline-style false --skip-tests
ng generate component components/about      --inline-style false --skip-tests
ng generate component components/experience --inline-style false --skip-tests
ng generate component components/projects   --inline-style false --skip-tests
ng generate component components/skills     --inline-style false --skip-tests
ng generate component components/hobbies    --inline-style false --skip-tests
ng generate component components/contact    --inline-style false --skip-tests
```

> `--standalone` is omitted because it is the **default** in Angular 21.

Each stub renders a `<section>` with a placeholder heading:
```html
<!-- e.g. src/app/components/hero/hero.component.html -->
<section id="hero"><h2>Hero (stub)</h2></section>
```

### 8. Create Content Directory
```
src/content/meta.json
src/content/experience.json
src/content/projects.json
src/content/skills.json
src/content/hobbies.json
```

Leave them as empty `{}` or `[]` for now — Step 02 fills them.

### 9. Create Asset Directories
```bash
mkdir -p public/assets/experience
mkdir -p public/assets/skills
mkdir -p public/assets/hobbies
```

### 10. Verify Dev Server
```bash
ng serve
```

The site should load at `http://localhost:4200` showing all stub sections.

---

## Acceptance Criteria
- [ ] `ng serve` starts without errors
- [ ] `ng build` produces a `dist/wimstienstra/browser/` folder without errors
- [ ] All seven section components render (as stubs) in the browser
- [ ] No leftover Angular boilerplate (default hero image, links to angular.io)
- [ ] `tsconfig.json` has `resolveJsonModule: true`
- [ ] `boneyard.config.json` exists at repo root
- [ ] Asset directories created under `public/assets/`
